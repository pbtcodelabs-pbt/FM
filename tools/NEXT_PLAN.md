## 🎯 مقصد
ایک ہی سبزی منڈی ایپ، دو طریقوں میں چلے — پیکج کے حساب سے:

### 1) اکیلا صارف (Single User) — بغیر فائربیس
- ایک موبائل، صرف مالک۔ **فائربیس کی کوئی چیز استعمال نہیں ہوگی** (نہ لاگ ان، نہ ڈیٹا)۔
- ڈیٹا صرف فون میں + **گوگل ڈرائیو** پر خودکار بیک اپ:
  - دن میں 2–3 بار خودکار بیک اپ (مثلاً صبح، دوپہر، شام) + ایپ بند کرتے وقت
  - ڈرائیو پر آخری 7–10 بیک اپ رکھیں، پرانے خود صاف
  - نئے فون پر "ڈرائیو سے بحال کریں" ایک بٹن سے
- اوپر واضح بینر/نشان: "📱 اکیلا صارف — ڈیٹا گوگل ڈرائیو پر"

### 2) ملٹی یوزر (Online) — فائربیس کے ساتھ، کئی موبائل
- سبزی منڈی کا **اپنا نیا فائربیس پروجیکٹ** (صدام والا کبھی نہیں)۔
- ہر دکان کا ڈیٹا اس کے **موبائل نمبر** (رجسٹریشن والا) کے حساب سے الگ: `shops/<mobile>/...`
- مالک (ایڈمن) + ملازم الگ الگ لاگ ان، ہر ملازم کی اپنی اسکرینیں/اجازتیں (صدام والی ایپ کا موجودہ نظام)۔
- گوگل ڈرائیو بیک اپ یہاں بھی رہے (اضافی حفاظت)۔

### 3) پیکج (سلاٹس) — ملازموں کی تعداد سے
| پیکج | افراد | طریقہ |
|---|---|---|
| P1 | صرف مالک | اکیلا صارف (ڈرائیو) |
| P2 | مالک + 1 ملازم | آن لائن |
| P3 | مالک + 2 ملازم | آن لائن |
| P4 | مالک + 3 ملازم | آن لائن |
| P5+ | مالک + 4، 5، 6… | آن لائن — ہر اضافی ملازم پر قیمت بڑھے |
- ملازموں کی حد **لائسنس** سے طے ہو: حد پوری ہو تو "نیا ملازم" بٹن بند + پیغام "پیکج بڑھائیں"۔
- پیکج بدلنا (مثلاً P1 → P3): ڈیٹا فون/ڈرائیو سے فائربیس پر خود منتقل ہو۔
- موجودہ 7 دن مفت آزمائش + لائسنس کا نظام اسی میں جوڑیں؛ ادائیگی نمبر **03206793793 (عبدالحفیظ)**۔
- ڈویلپر کی طرف سے پیکج/لائسنس کوڈ بنانے کا آسان طریقہ۔

## 🛠️ کام کی ترتیب (تجویز)
1. سیٹنگ میں "پیکج / طریقہ" کا خانہ + بینر (ابھی صرف اکیلا صارف فعال)
2. اکیلا صارف: خودکار ڈرائیو بیک اپ (دن میں 2–3 بار) + بحالی
3. نیا فائربیس پروجیکٹ (صارف بنائے گا، Claude قدم بہ قدم بتائے) → `build_general.py` میں کلاؤڈ بند کرنے کی جگہ سبزی منڈی کا فائربیس + `shops/<mobile>` راستے
4. ملازموں کی حد لائسنس سے
5. **پلے سٹور (APK + AAB)** — سبزی منڈی **پلے سٹور** پر جائے گی (صدام والی نہیں — وہ صرف PWABuilder کی APK سے ملازموں کے لیے)۔
   - MCS ریپو کا `.github/workflows/build-android.yml` (Bubblewrap + JDK17 + Android SDK دستی، keystore GitHub Secret میں، ورژن کوڈ = run_number) نمونہ ہے — اسے SM کے لیے بدلیں؛ **سبزی منڈی کی اپنی الگ چابی (keystore)**۔
   - ⚠️ `assetlinks.json` ڈومین کی **جڑ** پر چاہیے (`/.well-known/assetlinks.json`)۔ ابھی SM `pbtcodelabs-pbt.github.io/SM/` (ذیلی فولڈر) پر ہے — وہاں نہیں چلے گا۔ حل: سبزی منڈی کا اپنا فائربیس ہوسٹنگ (جو ویسے بھی آن لائن پیکج کے لیے بن رہا ہے) یا اپنا ڈومین۔ فائربیس پر `firebase.json` میں `**/.*` والی ignore سے `.well-known` کو نکالنا ہوگا۔
   - پہلے ایپ مکمل (P1 + آن لائن پیکج)، پھر پلے سٹور۔

- اکیلا صارف طریقے میں فائربیس کی کوئی درخواست نہیں جانی چاہیے (موجودہ fetch بلاک برقرار)۔
